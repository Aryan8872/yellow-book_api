## Objective

Change the redemption code time-to-live (TTL) from 180 seconds to 86400 seconds (1 day) to give users sufficient time to travel to merchant locations.

---

## Context

### Locked Decisions from CONTEXT.md
- **D-11:** Change redemption code/QR TTL from 180 seconds to 1 day — gives users time to travel to merchant location
- **D-12:** QR expires after 1 day if unused
- **D-13:** QR expires immediately after merchant scans it — cannot be regenerated — uniqueness maintained via RedemptionSession status

### Research Findings from RESEARCH.md
- Simple constant change in `redemption.constants.ts`
- No distributed lock changes needed
- Schema already supports TTL via `codeExpiresAt` field

### Existing Code Patterns

- `src/modules/redemption/redemption.service.ts` — TTL usage in code generation
