## Objective

Replace unsafe `(req as any).user` type assertions with a properly typed `@CurrentUser()` decorator to improve type safety and eliminate the use of `as any`.

---

## Context

### Research Findings from RESEARCH.md
- NestJS provides `createParamDecorator` for custom parameter decorators
- Current pattern uses `(req as any).user as AuthenticatedUser` which undermines TypeScript
- Recommended pattern: `@CurrentUser() user: AuthenticatedUser`

### Existing Code Patterns
- `src/modules/merchant/merchant.controller.ts` - Uses `getUser(req: Request)` helper
- `src/modules/offer/offer.controller.ts` - Uses `(req as any).user` directly
- `src/modules/auth/auth.controller.ts` - Uses `@CurrentUser('id')` decorator

```typescript
import { createParamDecorator, ExecutionContext } from '@nestjs/common';
import type { AuthenticatedUser } from '../../modules/auth/auth.types';

export const CurrentUser = createParamDecorator(
  (data: unknown, ctx: ExecutionContext): AuthenticatedUser => {
    const request = ctx.switchToHttp().getRequest();
    return request.user as AuthenticatedUser;
  },
);
```

### Task 2: Replace (req as any).user in Merchant Controller

**Type:** feature
**Files:** `src/modules/merchant/merchant.controller.ts`

**Action:**
Remove the `getUser()` helper method and replace all usages with `@CurrentUser()` decorator:
```typescript
// Remove this method:
private getUser(req: Request): AuthenticatedUser {
  return (req as any).user as AuthenticatedUser;
}

// Replace all method signatures:
// Before:
async createMerchant(@Body() dto: CreateMerchantDto, @Req() req: Request) {
  return this.merchantService.createMerchant(dto, this.getUser(req));
}

// After:
async createMerchant(@Body() dto: CreateMerchantDto, @CurrentUser() user: AuthenticatedUser) {
  return this.merchantService.createMerchant(dto, user);
}
```

Remove `@Req()` decorator and `Request` import.

**Verify:**
- `getUser()` method removed
- All methods use `@CurrentUser()` instead of `getUser(req)`
- `@Req()` decorator removed from all methods
- `Request` import removed if no longer used

**Done:** Merchant controller updated
