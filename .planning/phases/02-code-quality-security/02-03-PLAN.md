## Objective

Extract repeated merchant ownership checks from service methods into a shared guard to improve code reuse and maintainability.

---

## Context

### Research Findings from RESEARCH.md
- Current pattern repeats ownership checks in service methods
- NestJS Guards can enforce access control at the controller level
- Custom guards can access request parameters and user context

### Existing Code Patterns
- `src/modules/merchant/merchant.service.ts` - Repeated ownership checks:

## Tasks

### Task 1: Create MerchantOwnershipGuard

**Type:** scaffold
**Files:** `src/modules/merchant/guards/merchant-ownership.guard.ts`

**Action:**
Create the guard with ownership logic:
```typescript
import { Injectable, CanActivate, ExecutionContext, ForbiddenException } from '@nestjs/common';
import { UserRole } from '@prisma/client';

@Injectable()
export class MerchantOwnershipGuard implements CanActivate {
  canActivate(context: ExecutionContext): boolean {
    const request = context.switchToHttp().getRequest();
    const user = request.user;
    
    // Extract merchantId from params or body
    const merchantId = request.params.merchantId || request.body.merchantId;
    
    // Admins can access any merchant
    if (user.role === UserRole.ADMIN) return true;
    
    // Merchant users can only access their own merchant
    if (user.merchantId === merchantId) return true;
    
    throw new ForbiddenException('Access denied');
  }
}
```

**Verify:**
- Guard file created at correct path
- Guard implements CanActivate
- Admin bypass logic included
- Merchant ownership check implemented

**Done:** MerchantOwnershipGuard created

### Task 3: Apply Guard to Merchant Controller

**Type:** feature
**Files:** `src/modules/merchant/merchant.controller.ts`

**Action:**
Add guard to controller and endpoints:
```typescript
import { MerchantOwnershipGuard } from './guards/merchant-ownership.guard';

@Controller('merchants')
@UseGuards(JwtAuthGuard, RolesGuard)
export class MerchantController {
  // Apply guard to endpoints that need ownership check
  @Get(':id')
  @UseGuards(MerchantOwnershipGuard)
  async getMerchant(@Param('id') id: string, @CurrentUser() user: AuthenticatedUser) {
    return this.merchantService.getMerchant(id, user);
  }

  @Put(':id')
  @Roles(UserRole.ADMIN, UserRole.MERCHANT_ADMIN)
  @UseGuards(MerchantOwnershipGuard)
  async updateMerchant(@Param('id') id: string, @Body() dto: UpdateMerchantDto, @CurrentUser() user: AuthenticatedUser) {
    return this.merchantService.updateMerchant(id, dto, user);
  }

  @Post(':merchantId/branches')
  @Roles(UserRole.ADMIN, UserRole.MERCHANT_ADMIN)
  @UseGuards(MerchantOwnershipGuard)
  async createBranch(@Param('merchantId') merchantId: string, @Body() dto: CreateBranchDto, @CurrentUser() user: AuthenticatedUser) {
    return this.merchantService.createBranch(merchantId, dto, user);
  }

  @Get(':merchantId/branches')
  @UseGuards(MerchantOwnershipGuard)
  async getBranches(@Param('merchantId') merchantId: string, @CurrentUser() user: AuthenticatedUser) {
    return this.merchantService.getBranches(merchantId, user);
  }
}
```

**Verify:**
- Guard imported
- Guard applied to relevant endpoints
- Admin-only endpoints (createMerchant) don't need guard (already role-protected)

**Done:** Guard applied to controller
