# Plan 03-06: Paginated Search APIs for Admin Panel

**Phase:** Phase 3 - Admin Module  
**Status:** Planned  
**Estimated Effort:** 1-2 days

## Objective

Add comprehensive paginated search APIs for merchants, branches, and redemptions to support table display in the admin panel with search, filter, and sort capabilities.

## Current State

- **Admin Module:** Has basic pagination DTOs (`ListMerchantsDto`, `ListUsersDto`) with page/limit and basic filters
- **Merchant Controller:** Has single merchant get and branches-by-merchant, but no paginated list for all merchants/branches
- **Redemption Controller:** Only has redemption initiation/completion endpoints, no list endpoint
- **Missing:** Search functionality, sorting, advanced filters for admin panel tables

## API Endpoints

### Merchants
- `GET /api/v1/admin/merchants` - List merchants with search/filter/sort (updated)
- `GET /api/v1/merchants` - List all merchants (admin only, new)

### Branches
- `GET /api/v1/merchants/branches/all` - List all branches with search/filter/sort (new)

### Redemptions
- `GET /api/v1/redemptions/sessions` - List redemption sessions with search/filter/sort (new)

## Query Parameters

### Common (PaginationDto)
- `page` - Page number (default: 1)
- `limit` - Items per page (default: 20)
- `search` - Search string (searches across multiple fields)
- `sortBy` - Field to sort by
- `sortOrder` - Sort direction: asc or desc (default: asc)

### Merchants
- `status` - Filter by status (PENDING_REVIEW, ACTIVE, SUSPENDED)

### Branches
- `merchantId` - Filter by merchant
- `city` - Filter by city
- `isActive` - Filter by active status

### Redemptions
- `merchantId` - Filter by merchant
- `offerId` - Filter by offer
- `status` - Filter by redemption status
- `startDate` - Filter by start date (ISO 8601)
- `endDate` - Filter by end date (ISO 8601)
